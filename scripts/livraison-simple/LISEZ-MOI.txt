GESSTOCK - INSTALLATION SIMPLE
==============================

Ce dossier contient :
  gesstock.jar              le programme (avec son interface)
  base-de-lancement.sql     la base de données prête à l'emploi : toutes les tables et le compte administrateur
  importer-la-base.cmd      met la base dans MySQL (une seule fois)
  demarrer.cmd              lance GesStock
  sauvegarder-la-base.cmd   sauvegarde la base (avant chaque mise à jour ; elle se fait aussi toute seule chaque jour)
  choisir-la-copie-des-sauvegardes.cmd   envoie une copie de chaque sauvegarde sur une clé USB ou un autre disque
  restaurer-une-sauvegarde.cmd           remet la base dans l'état d'une sauvegarde (après une panne ou une erreur)

Ce qu'il faut déjà avoir sur le serveur : Java 17 et WampServer (icône verte, MySQL 8.4).


INSTALLATION (4 gestes)
-----------------------
1. Copiez tout ce dossier sur le serveur, à un endroit simple, par exemple  C:\GesStock
   (pas sur le Bureau, pas dans Téléchargements).

2. Double-cliquez sur  importer-la-base.cmd  (une seule fois).
   Vous devez voir : "Base importée".
   Si le message parle d'une base qui existe déjà, c'est qu'une installation est déjà là : ne tapez PAS "EFFACER",
   sauf si vous voulez repartir de zéro (tout serait perdu).

3. Double-cliquez sur  demarrer.cmd  et gardez la fenêtre ouverte (la fermer arrête GesStock).
   Attendez environ une minute. Windows peut demander d'autoriser Java sur le réseau : cliquez sur "Autoriser".

4. Ouvrez Chrome ou Edge et tapez  http://localhost:8080  (la fenêtre de demarrer.cmd affiche aussi les adresses
   à utiliser depuis les autres postes, par exemple  http://192.168.1.23:8080).
   Identifiant : admin        Mot de passe : celui qui vous a été communiqué (il n'est écrit nulle part ici).


DÉMARRAGE AUTOMATIQUE (recommandé chez un client)
-------------------------------------------------
Sans cela, GesStock s'arrête quand le PC s'éteint et il faut double-cliquer à nouveau sur demarrer.cmd. Avec le démarrage
automatique, GesStock se lance tout seul avec Windows, sans aucune fenêtre ni message, et le navigateur s'ouvre sur la page de
connexion quand GesStock est prêt. Il installe aussi la SAUVEGARDE AUTOMATIQUE quotidienne de la base (voir plus bas).

1. Vérifiez d'abord que tout marche avec demarrer.cmd (les 4 gestes ci-dessus), puis fermez la fenêtre de demarrer.cmd.
2. Double-cliquez sur  installer-demarrage-automatique.cmd , répondez "Oui" à la demande de Windows, puis attendez le message
   vert "GesStock fonctionne et démarrera tout seul avec ce PC". Une fois fait, n'utilisez plus demarrer.cmd.
3. Vérifiez : Démarrer > Redémarrer, connectez-vous à Windows et attendez. Le navigateur s'ouvre tout seul sur la page de
   connexion, mais seulement quand GesStock est vraiment prêt : environ 2 minutes après le démarrage sur un PC récent à disque
   SSD ; sur un vieux PC à disque dur classique, Windows lui-même est très lent juste après le démarrage et cela peut prendre
   10 minutes ou plus (le navigateur attend patiemment jusqu'à 20 minutes, il ne s'ouvre pas avant). Le serveur démarre même
   si personne ne se connecte à Windows : les autres postes du réseau y accèdent dès qu'il est prêt.
   Chez un client, un disque SSD est le meilleur investissement : le même GesStock y démarre en moins de 30 secondes.

SAUVEGARDER LA BASE
-------------------
Automatiquement : une fois le démarrage automatique installé (voir plus haut), la base est sauvegardée TOUTE SEULE chaque jour
à 13 h, sans fenêtre. Si le PC est éteint à cette heure, la sauvegarde se fait dès qu'il est rallumé. Les 30 sauvegardes les plus
récentes sont gardées, les plus anciennes sont effacées. Le résultat de chacune est noté dans
sauvegardes\journal-sauvegardes.txt (une ligne ECHEC y signale un problème : regardez que WampServer est bien démarré).

À la main : double-cliquez sur  sauvegarder-la-base.cmd  (WampServer démarré, icône verte ; GesStock peut rester allumé).
Un fichier daté est créé dans le sous-dossier "sauvegardes", par exemple  sauvegardes\{{NOM_BASE}}-2026-11-05_18-30.sql .
Faites-le TOUJOURS avant une mise à jour.

Sur une clé USB : une sauvegarde restée sur le même PC est perdue avec lui (panne du disque, vol, incendie). Branchez une clé
USB, double-cliquez sur  choisir-la-copie-des-sauvegardes.cmd  et tapez le dossier de la clé, par exemple  E:\GesStock-Sauvegardes .
Chaque sauvegarde y sera copiée automatiquement (la clé doit rester branchée ; si elle est absente, la sauvegarde reste sur le
PC et le journal des sauvegardes le dit).


RESTAURER UNE SAUVEGARDE
------------------------
À faire après une panne, une erreur de manipulation ou un disque remplacé : double-cliquez sur  restaurer-une-sauvegarde.cmd ,
répondez "Oui" à la demande de Windows, choisissez le numéro de la sauvegarde, puis tapez RESTAURER. Le programme arrête GesStock,
fait d'abord une copie de l'état actuel (sauvegardes\avant-restauration-....sql), remet la base dans l'état choisi et relance GesStock.
Tout ce qui a été enregistré APRÈS la sauvegarde choisie est retiré de GesStock : choisissez la plus récente sauf raison contraire.


METTRE À JOUR GESSTOCK (nouvelle version du programme)
------------------------------------------------------
1. Double-cliquez sur  sauvegarder-la-base.cmd  et attendez "Sauvegarde terminée". Si elle échoue, n'allez pas plus loin.
2. Double-cliquez sur  outils\arreter.cmd  (GesStock s'arrête).
3. Remplacez gesstock.jar par le nouveau (et les autres fichiers fournis avec lui, le cas échéant).
4. Relancez GesStock : installer-demarrage-automatique.cmd si le démarrage automatique est installé, sinon demarrer.cmd.
   Le premier démarrage après une mise à jour peut être plus long : GesStock met la base à jour toute seule.
5. Connectez-vous et vérifiez le stock de quelques articles et la dernière vente.

Le sous-dossier "outils" contient le reste :
  arreter.cmd                        arrête GesStock (avant une mise à jour du programme ou une restauration de la base)
  desactiver-demarrage-automatique.cmd   retire le démarrage automatique (la base et les fichiers ne sont pas touchés)


APRÈS LA PREMIÈRE CONNEXION
---------------------------
- Changez le mot de passe de l'administrateur : menu "Administration", modifier l'utilisateur "admin".
- Menu "Entreprise" : nom, adresse, téléphone, logo (ils apparaissent sur les tickets et les documents imprimés).
- Menu "Administration" : un compte par personne (ADMIN, MANAGER, GESTIONNAIRE, CAISSIER).
- Menu "Articles" : catégories, unités, articles. Menu "Caisse & ventes" : ouvrir la caisse, puis vendre.


RÉGLAGES (facultatif)
---------------------
Ouvrez demarrer.cmd avec le Bloc-notes (clic droit > Modifier) : les lignes "set" tout en haut donnent le port, le
fuseau horaire du pays (Africa/Dakar, Africa/Abidjan, Africa/Douala...), le taux de TVA (0 = pas de TVA), si les prix
sont TTC (true) ou HT (false), la mémoire de Java et ses options (réglées pour un démarrage rapide : ne les changez pas
sans raison). Enregistrez, puis arrêtez GesStock (outils\arreter.cmd) et relancez-le (demarrer.cmd, ou
installer-demarrage-automatique.cmd si le démarrage automatique est installé).


À SAVOIR
--------
- La sauvegarde automatique n'existe qu'avec le démarrage automatique installé ; sans lui, pensez à sauvegarder-la-base.cmd (au
  moins une fois par semaine). Dans tous les cas, faites copier les sauvegardes sur une clé USB (voir plus haut).
- Sans le démarrage automatique, après un redémarrage du PC il faut double-cliquer à nouveau sur demarrer.cmd.
- Les messages de GesStock sont dans le sous-dossier "journaux" (créé au premier démarrage).
- En cas de problème, envoyez une photo de l'écran et le fichier journaux\gesstock.log.
