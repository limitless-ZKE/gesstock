GESSTOCK - INSTALLATION SIMPLE
==============================

Ce dossier contient :
  gesstock.jar              le programme (avec son interface)
  base-de-lancement.sql     la base de données prête à l'emploi : toutes les tables et le compte administrateur
  importer-la-base.cmd      met la base dans MySQL (une seule fois)
  demarrer.cmd              lance GesStock

Ce qu'il faut déjà avoir sur le serveur : Java 17 et WampServer (icône verte, MySQL 8.4).


INSTALLATION (4 gestes)
-----------------------
1. Copiez tout ce dossier sur le serveur, à un endroit simple, par exemple  C:\GesStock
   (pas sur le Bureau, pas dans Téléchargements).

2. Double-cliquez sur  importer-la-base.cmd  (une seule fois).
   Vous devez voir : "Base importée".
   Si le message parle d'une base qui existe déjà, c'est qu'une installation est déjà là : ne tapez PAS "EFFACER",
   sauf si vous voulez repartir de zéro (tout serait perdu).

3. Double-cliquez sur  demarrer.cmd  et gardez la fenêtre ouverte (la fermer arrête GesStock).
   Attendez environ une minute. Windows peut demander d'autoriser Java sur le réseau : cliquez sur "Autoriser".

4. Ouvrez Chrome ou Edge et tapez  http://localhost:8080  (la fenêtre de demarrer.cmd affiche aussi les adresses
   à utiliser depuis les autres postes, par exemple  http://192.168.1.23:8080).
   Identifiant : admin        Mot de passe : celui qui vous a été communiqué (il n'est écrit nulle part ici).


DÉMARRAGE AUTOMATIQUE (recommandé chez un client)
-------------------------------------------------
Sans cela, GesStock s'arrête quand le PC s'éteint et il faut double-cliquer à nouveau sur demarrer.cmd. Avec le démarrage
automatique, GesStock se lance tout seul avec Windows, sans aucune fenêtre ni message, et le navigateur s'ouvre sur la page de
connexion quand GesStock est prêt.

1. Vérifiez d'abord que tout marche avec demarrer.cmd (les 4 gestes ci-dessus), puis fermez la fenêtre de demarrer.cmd.
2. Double-cliquez sur  installer-demarrage-automatique.cmd , répondez "Oui" à la demande de Windows, puis attendez le message
   vert "GesStock fonctionne et démarrera tout seul avec ce PC". Une fois fait, n'utilisez plus demarrer.cmd.
3. Vérifiez : Démarrer > Redémarrer, connectez-vous à Windows et attendez. Une à quatre minutes plus tard, le navigateur
   s'ouvre tout seul sur la page de connexion. Le serveur démarre même si personne ne se connecte à Windows : les autres postes
   du réseau y accèdent dès qu'il est prêt.

Le sous-dossier "outils" contient le reste :
  arreter.cmd                        arrête GesStock (avant une mise à jour du programme ou une restauration de la base)
  desactiver-demarrage-automatique.cmd   retire le démarrage automatique (la base et les fichiers ne sont pas touchés)
Mise à jour de gesstock.jar : arreter.cmd, remplacer gesstock.jar par le nouveau, puis relancer
installer-demarrage-automatique.cmd (il relance GesStock tout de suite).


APRÈS LA PREMIÈRE CONNEXION
---------------------------
- Changez le mot de passe de l'administrateur : menu "Administration", modifier l'utilisateur "admin".
- Menu "Entreprise" : nom, adresse, téléphone, logo (ils apparaissent sur les tickets et les documents imprimés).
- Menu "Administration" : un compte par personne (ADMIN, MANAGER, GESTIONNAIRE, CAISSIER).
- Menu "Articles" : catégories, unités, articles. Menu "Caisse & ventes" : ouvrir la caisse, puis vendre.


RÉGLAGES (facultatif)
---------------------
Ouvrez demarrer.cmd avec le Bloc-notes (clic droit > Modifier) : les cinq lignes "set" tout en haut donnent le port, le
fuseau horaire du pays (Africa/Dakar, Africa/Abidjan, Africa/Douala...), le taux de TVA (0 = pas de TVA) et si les prix
sont TTC (true) ou HT (false). Enregistrez, fermez la fenêtre de GesStock et relancez demarrer.cmd.


À SAVOIR
--------
- Ce dossier ne contient pas de sauvegarde automatique. Les données sont dans MySQL (C:\wamp64\bin\mysql) : faites une
  copie régulière de la base (icône Wamp > phpMyAdmin > base "{{NOM_BASE}}" > Exporter).
- Sans le démarrage automatique, après un redémarrage du PC il faut double-cliquer à nouveau sur demarrer.cmd.
- Les messages de GesStock sont dans le sous-dossier "journaux" (créé au premier démarrage).
- En cas de problème, envoyez une photo de l'écran et le fichier journaux\gesstock.log.
